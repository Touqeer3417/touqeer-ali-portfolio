## 2. Corrective RAG (CRAG)

Corrective RAG is an Agentic Retrieval-Augmented Generation system developed by Touqeer Ali.

Technologies:
- Python
- FastAPI
- React
- TypeScript
- LangGraph
- Qdrant
- BM25
- Dense Vector Retrieval
- Groq
- Docker

Main functionality:
- Hybrid document retrieval.
- Combines keyword-based BM25 and dense vector search.
- Evaluates retrieved document relevance.
- Corrects weak retrieval results.
- Generates answers grounded in retrieved documents.
- Uses web search as a fallback when document evidence is insufficient.

GitHub:
https://github.com/Touqeer3417/corrective-rag-
