
Optimizing Chatbot Time

👉 Fixing Embedding Latency
Cache embeddings for repeated or similar queries
Use smaller, faster embedding models
Pre-embed common query templates
Batch embedding requests

👉 Fixing with Chunk Inefficiencies
Use smaller semantic chunks (300–500 tokens)
Avoid sending entire documents
Store summaries along with raw chunks
Retrieve summaries first, drill down only if needed

👉 Fixing Vector Search Latency
Reduce top-k results
Use ANN instead of exact search
Tune index parameters (HNSW / IVF)
Use hybrid search:
→ BM25 to narrow candidates
→ Vector search on the reduced set

👉 Fixing Re-ranking
Skip re-ranking for low-risk queries
Use lightweight cross-encoders
Re-rank top-5 results, not top-20.

👉 LLM Inference Is the Bottleneck
Use faster models for retrieval-QA
Draft with a small model, escalate only if needed
Reduce max tokens
